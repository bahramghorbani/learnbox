# LearnBox least-privilege role baseline (N2 recovery evidence).
#
# Captured READ-ONLY from the Production database on 2026-10-12 with
# infrastructure/production/ops/learnbox-recovery-drill.sh --capture, at migration ledger head
# 0034_admin_pack_metadata_grants. The database name is normalised to <DB> so the same baseline
# compares against a recovery target with any name.
#
# This file is DATA, not a second implementation of the grant model. The grants themselves live in
# infrastructure/database/db-roles-p0.sql plus the role-guarded blocks of migrations 0023, 0028,
# 0029, 0030, 0031, 0032, 0033 and 0034. The drill reproduces them on a disposable database and
# diffs the result against this file, so a future migration that adds a grant without updating the
# role model is caught as a difference instead of being discovered during a recovery.
#
# Equality is asserted for learnbox_app and learnbox_admin: those two are the runtime security
# boundary, and both a MISSING and an EXTRA line is a failure. learnbox_migrator is the backup and
# ledger role; its full-verb set depends on which tables existed at cutover time, so only its
# SELECT coverage over every table and sequence is asserted.
