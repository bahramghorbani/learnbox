# Routine worker reports

Create exactly one `<task-id>.md` report when a queue item moves to `review_requested`. Use these
fields verbatim:

- Branch:
- Base commit:
- Head commit:
- Draft PR:
- Scope completed:
- Files changed:
- Checks run:
- Checks unavailable:
- Remaining work:
- Risks:
- Secrets or production changes:
- Bobo canonical status:

Never include secrets, credentials, personal data, phone numbers, OTP values or private URLs.
