# LearnBox storyboard and delivery status

The original 30-stage storyboard remains historical planning context. Delivery is now governed by the product milestones in `ROADMAP.md`; the project is no longer interpreted as thirty serial micro-tasks.

## Current product stage

**M1 and M2 active in controlled parallel — both partial and not production-ready**

## Milestone map

| Milestone | Outcome                                                                   | Status    |
| --------- | ------------------------------------------------------------------------- | --------- |
| M0        | Product truth, boundaries, inventory and documentation governance         | completed |
| M1        | Online learning core with free 35-word A1 pack and reconnect sync         | partial   |
| M2        | AI content factory and Admin content operations                           | partial   |
| M3        | Profile, settings, purchases, sync status and personal vocabulary         | planned   |
| M4        | Web bank, Cafe Bazaar and Apple StoreKit commerce with shared entitlement | planned   |
| M5        | Native online Android and iOS preparation                                 | planned   |
| M6        | Closed beta hardening and invited cohort operations                       | planned   |
| M7        | Android public release and Cafe Bazaar operations                         | planned   |
| M8        | Native iOS App Store release                                              | planned   |

`partial` means verified foundations and merged slices exist, but the milestone exit criteria in
`ROADMAP.md` are not complete. M1 still lacks an enabled end-to-end server-backed learning/sync
journey and release-approved seeded Starter content. M2 has verified staging authentication and
truthful local review foundations, but review persistence, complete media/approval gates and a real
pack release remain unfinished. Production, payment, seed and publication remain gated.

## Retained foundations

The repository retains completed evidence for product foundation, learner shell, review engine, media/audio foundations, web flows, offline tolerance, admin review foundations, splash experience and dormant native-auth seams. Those foundations are not automatically commercial release features; current status is in `docs/PRODUCT_STATUS.md`.

## Product direction

LearnBox is online-first and offline-tolerant. The landing site is independent. Premium packs are complete AI-assisted, human-reviewed vocabulary products. Web uses a direct bank gateway, Android uses Cafe Bazaar billing and iOS uses Apple IAP; verified purchases map to shared backend entitlements.
