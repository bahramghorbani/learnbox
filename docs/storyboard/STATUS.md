## Retained foundations

The repository retains completed evidence for product foundation, learner shell, review engine, media/audio foundations, web flows, offline tolerance, admin review foundations, splash experience and dormant native-auth seams. Those foundations are not automatically commercial release features; current status is in `docs/PRODUCT_STATUS.md`.

## Product direction

LearnBox is online-first and offline-tolerant. The landing site is independent. Premium packs are complete AI-assisted, human-reviewed vocabulary products. Web uses a direct bank gateway, Android uses Cafe Bazaar billing and iOS uses Apple IAP; verified purchases map to shared backend entitlements.
