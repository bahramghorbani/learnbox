# Feature catalog

Core: OTP onboarding, Today, adaptive review, cards, personal vocabulary, offline sync and the
permanent `learnbox_start` entitlement. Start includes the complete core loop, retained learned
content, unlimited due review, basic progress/gamification, standard media and a remotely
configured personal-word limit. `learnbox_plus` is an entitlement extension, not a second app.

Next controlled work: Start 20-item vertical slice, remote-config client adapter, eligible-but-
nonaggressive Plus offer, analytics adapter, admin configuration and content factory tooling.
Later: extended levels and specialist packs, notifications, provider billing, AI assistance and
cross-device sync. Every feature requires tests, RTL/accessibility review, analytics intent, and a
rollback assessment.
