# راه‌اندازی فضای خصوصی رسانهٔ LearnBox

این کار فقط یک فضای خصوصی برای رسانه‌های آلفا می‌سازد. هنوز هیچ فایلی بارگذاری، هیچ آدرسی عمومی و هیچ دعوت‌نامه‌ای ایجاد نمی‌شود.

## وضعیت فعلی

فروشگاه خصوصی `learnbox-media-private` به پروژهٔ `learnbox-preview` متصل است و برای سه محیط
Development، Preview و Production فعال است. این اتصال از OIDC استفاده می‌کند؛ بنابراین
`BLOB_READ_WRITE_TOKEN` لازم نیست و نباید ساخته یا در گفتگو ارسال شود.

## کاری که مالک انجام می‌دهد

1. وارد [Vercel Dashboard](https://vercel.com/dashboard) شوید.
2. پروژهٔ **learnbox-preview** را باز کنید.
3. از منوی کناری، **Storage** را بزنید.
4. **Create Database** و سپس **Blob** را انتخاب کنید.
5. نام را دقیقاً `learnbox-media-private` وارد کنید.
6. در بخش دسترسی، **Private** را انتخاب کنید؛ نه Public.
7. Create را بزنید و اگر Vercel قوانین یا هزینه را نشان داد، فقط در صورت پذیرش خودتان تأیید کنید.
8. پس از ساخته‌شدن، در تب **Projects** مطمئن شوید پروژهٔ `learnbox-preview` برای هر سه محیط
   Development، Preview و Production متصل است. کلید، Token یا متغیر محیطی را ارسال نکنید.

## پس از تأیید مالک

Codex ابتدا با `pnpm exec vercel env pull .env.vercel.local --environment=development` از داخل
`apps/website` یک توکن کوتاه‌عمر OIDC را فقط روی همین دستگاه همگام می‌کند. سپس مسیر خصوصی
خواندن، بارگذاری کنترل‌شده، تطبیق ۶۰ اثرانگشت و رسیدهای اتصال را تکمیل می‌کند. هیچ رسانه‌ای
بدون این تطبیق و تأیید جداگانهٔ انتشار به کارت کاربران وصل نمی‌شود.

## مرز دسترسی

Vercel یک توکن کوتاه‌عمر OIDC و شناسهٔ فروشگاه را فقط در فایل محلی نادیده‌گرفته‌شده می‌نویسد.
این مقادیر هرگز نباید در گفتگو یا GitHub ارسال شوند. Codex فقط پس از ورود امن مالک و تأیید صریح
برای بارگذاری، آن‌ها را روی همین دستگاه می‌خواند و ۶۰ فایل را با اثرانگشت‌های ثبت‌شده تطبیق می‌دهد.
