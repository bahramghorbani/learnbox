# پیش‌نمایش خصوصی آلفا

این راهنما فقط برای اجرای محلی یا محیط پیش‌نمایشِ دسترسی‌محدود است. استفاده از آن به‌معنای انتشار عمومی، ارسال دعوت‌نامه یا فعال‌سازی آلفا نیست.

## اجرای محلی نسخهٔ تولیدی

1. از ریشهٔ پروژه، `pnpm build` را اجرا کن.
2. `pnpm preview:web` را اجرا کن.
3. فقط روی همان دستگاه، `http://127.0.0.1:3010` را باز کن.
4. مسیر اصلی و صفحهٔ آفلاین را با `CLOSED_ALPHA_EVIDENCE.md` ثبت کن.

برای سرویس‌های وابستهٔ محلی، فقط در صورت نیاز `docker compose up -d` اجرا می‌شود. پیکربندی فعلی با دادهٔ توسعه است و هرگز برای اینترنت عمومی مناسب نیست.

## پیش‌نمایش میزبانی‌شده

پیکربندی `apps/website/vercel.json` برای ساخت پیش‌نمایش خصوصی آماده است. هنگام ایجاد پروژه در Vercel، ریشهٔ پروژه باید `apps/website` باشد. این کار تنها پس از ورود و تأیید مالک انجام می‌شود؛ هیچ حساب واقعی، پیامک، پرداخت یا دادهٔ شخصی در پیش‌نمایش فعال نمی‌شود.

## مرزهای قطعی

- آدرس اینترنتی عمومی، حساب واقعی، پرداخت، اعلان و پیامک واقعی در این راهنما فعال نمی‌شوند.
- پیش‌نمایش بیرونی یا دعوت کاربر فقط پس از تأیید صریح مالک و تکمیل شواهد آلفا مجاز است.
- اگر به هر سرویس واقعی نیاز شد، ابتدا روش دسترسی، دادهٔ منتقل‌شونده و هزینه توضیح داده می‌شود تا مالک آن را تأیید کند.
