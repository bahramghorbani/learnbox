## کنترل‌های خودکار

- [ ] `pnpm check` موفق است.
- [ ] `pnpm build` موفق است.
- [ ] `node scripts/validate-migrations.mjs` موفق است.
- [ ] `pnpm audit --prod --audit-level=high` بدون آسیب‌پذیری شناخته‌شده است.
- [ ] `pnpm verify:alpha` موفق است و `config/closed-alpha.json` همچنان خاموش است.
- [ ] وضعیت CI همین ثبت در GitHub سبز است.
