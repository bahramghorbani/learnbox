# Owner actions

## LearnBox Start 20-card review

Before the first 20 Start cards can receive images or audio, nominate one qualified German/Persian
reviewer. The reviewer must be able to check German grammar and naturalness as well as Persian
meaning and writing. Once nominated, they can use
[`START_A1_EDITORIAL_REVIEW_PACKET.md`](../content/START_A1_EDITORIAL_REVIEW_PACKET.md); no code,
payment or technical setup is required from them.
