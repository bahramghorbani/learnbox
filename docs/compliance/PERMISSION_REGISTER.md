# Permission register

No device permission is requested in foundation. Future permissions require documented purpose, user-facing explanation, fallback, data use, and marketplace justification; broad storage, clipboard, and accessibility access are prohibited without explicit user action.

Notification permission is optional. It will be requested only after a learner selects a reminder time and sees a clear explanation of the benefit. If denied, the app keeps the learner's local reminder preference without sending device notifications. The worker records only aggregate delivery/open events needed to reduce reminder frequency; it never stores notification free text as analytics.
