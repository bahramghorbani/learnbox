# PDR-010 — Article-aware German audio and media standards

- **Status:** approved
- **Date:** 2026-10-12
- **Extends:** [PDR-004](./PDR-004-LEARNBOX-START-CONTENT-PACK.md), [PDR-005](./PDR-005-LEARNING-CONTENT-FACTORY.md), and [`QUALITY_RULES.md`](../content/QUALITY_RULES.md)

## Context

LearnBox teaches German grammatical gender as part of the word, not as optional metadata. The
media engine already constructs noun word audio from canonical `article + lemma` and resolves a
voice role deterministically from that article. When this decision was written the shipped mapping
had only two distinct voices (`der=onyx`, `die=nova`, DAS unset, DAS audio refused). The owner
chose the final three-voice roster on 2026-10-15; see "Owner voice decision" below.

The approved Start V2 visual contract already names `flux.2-pro` and defines the LearnBox visual
language. Its model and contract remain the image standard.

## Decision

1. Article-aware voice separation is a permanent LearnBox learning feature. It must not be
   collapsed to one voice.
2. `der`, `die`, and `das` each require a distinct, stable voice with verified German-Germany
   (`de-DE` / Hochdeutsch) pronunciation. A noun's article and lemma are spoken together by the
   voice assigned to that article; that same resolved role voice is used for the card's canonical
   sentence audio.
3. Words without an article use one stable default voice. The default may equal an approved
   article voice; it is not a fourth mandatory voice.
4. A new or changed voice is not eligible for card generation, acceptance, attachment, or
   publication until it passes the qualification gate below. Provider availability, ASR output,
   or a successful HTTP response alone is not qualification.
5. `flux.2-pro`, the `1024x1024` image size, and the approved Start V2 visual contract remain
   required defaults for vocabulary-card image candidates. Future packs must supply a versioned
   visual contract and reviewed per-card briefs or concepts before image generation.

## Voice qualification gate

Before selecting the final roster, generate only an owner-authorized, low-volume candidate set
outside Production. For each proposed article voice and the default voice, the evidence must record:

- model ID, provider, exact voice ID, locale, prompt text, candidate checksum, and generation date;
- a word sample containing the correct article and lemma, plus a canonical German example sentence;
- an independent listener's explicit `de-DE` / Hochdeutsch decision for pronunciation, naturalness,
  article clarity, intelligibility, and absence of truncation or distortion;
- proof that the three article voices are audibly distinct; and
- the candidate cost and the owner-approved spend boundary.

A failed, unavailable, duplicated, or unreviewed candidate is rejected rather than falling back to
another article role. Existing approved Start media is preserved and is not regenerated by this
decision.

## Owner voice decision (2026-10-15)

**Decision:** `der=sage`, `die=nova`, `das=fable` on AvalAI `eleven_multilingual_v2`. The default
voice for words without an article stays `nova` (point 3 above allows it to equal an article voice).

**Basis:** the product owner personally listened to real samples and chose this roster. This is
the owner's listening decision. No native-speaker or expert pronunciation review was performed,
and this record makes no such claim.

## Current configuration

`apps/admin/lib/server/ai-media-config.ts` ships `der=sage`, `die=nova`, `das=fable`,
default=`nova`. The same mapping can be stated explicitly in an environment:

```
LEARNBOX_AI_VOICE_DER=sage
LEARNBOX_AI_VOICE_DIE=nova
LEARNBOX_AI_VOICE_DAS=fable
```

An environment value overrides the shipped value for that role. There is no fallback between
roles. Before every speech call (single-card generation, bulk generation and voice preview), the
same check `germanVoiceIssue` refuses all audio with a named error code when:

- `audio_model_not_qualified`: the audio model is not `eleven_multilingual_v2`;
- `voice_not_supported`: a voice id is not one AvalAI accepts for that model (`alloy`, `coral`,
  `echo`, `fable`, `nova`, `onyx`, `sage`, `shimmer`);
- `das_voice_unconfigured`: DAS is missing or equals DIE;
- `article_voices_not_distinct`: DER equals DIE or DAS.

A misconfigured or duplicated roster therefore stops audio for every article. It never speaks a
card in a different article's voice. `eleven_multilingual_v2` takes no language parameter, so the
spoken language comes from the canonical German text. Every candidate records `language=de` and
`locale=de-DE`.

This record itself changed no environment. **Update 2026-10-16:** the owner enabled Media AI in the
Production Admin with this exact roster set explicitly (`der=sage`, `die=nova`, `das=fable`,
default `nova`), image model `flux.2-pro`, audio model `eleven_multilingual_v2`, and
`LEARNBOX_AI_AUDIO_OUTPUT_FORMAT` unset. Live state:
[`ADMIN_PRODUCTION_STATUS.md`](../operations/ADMIN_PRODUCTION_STATUS.md). Any other environment
must be checked for an older `LEARNBOX_AI_VOICE_DER=onyx` or missing DAS value before media
generation is enabled there.

The repository records `coral` with `eleven_flash_v2_5` for historical Start candidates and
`alloy` with `gpt-4o-mini-tts` for an isolated repair attempt. Neither is qualification evidence
for `eleven_multilingual_v2`; no third voice may be selected from those records without the gate
above. The allowed AvalAI voice catalog and German quality under the eventual model are therefore
an owner-gated qualification question, not an assumption.

## Required media-quality boundary

- Image candidates require the visual contract, a reviewed subject brief/concept, semantic and
  mobile-readability review, and checks for generated text, watermark, clutter and provenance.
- Audio candidates require the article/lemma or canonical sentence target, the qualified role
  voice, format checks, listening QA and recorded provenance.
- All six content-review dimensions remain required before publication. Candidate generation,
  acceptance and publication remain separate actions; AI cannot publish.

## Owner pack-content decisions (2026-10-16)

These are binding for every new pack and are implemented by the shared card standard
(`packages/content-models/src/card-standard.ts`) and the Admin media services in release `15e6783`.

1. **Starter is the reference.** New cards keep the appearance, field set and layout of the 35
   approved Starter cards. The card standard restates that shape; it does not invent a new one.
2. **No Bobo in new images.** Newly generated card images never contain Bobo or any mascot, and
   never contain text. A subject that names Bobo is refused before the provider is called. This
   supersedes, for newly generated vocabulary images, the Bobo-presence guidance of
   [PDR-003](./PDR-003-BOBO-VISUAL-VOCABULARY.md) and the matching sentence in `QUALITY_RULES.md`.
   The five approved Starter images that show Bobo (`start-a1-familie`, `-freund`, `-freundin`,
   `-mutter`, `-schwester`) are historical, stay valid, and are not regenerated.
3. **Voices.** `der=sage`, `die=nova`, `das=fable`, default `nova`. The example-sentence audio uses
   the same voice as the card's word audio.
4. **Completeness and the human gate.** A card is complete only when its canonical text passes the
   card standard and it has accepted, valid image, word audio and example audio. An incomplete card
   may be saved as Draft. Submitting for review requires complete text; publishing additionally
   requires the accepted, valid media. Generation never accepts;
   acceptance never publishes; publication is an explicit human action per pack after all six review
   dimensions. AI never publishes.
5. **Starter is never changed automatically.** No generation, Repair, import or media run edits
   the Starter pack, its 35 cards or its 105 media. A Starter correction (for example #427) is a new
   reviewed card version under its own owner decision.
6. **AvalAI cost is owned by the owner.** The product has no programmatic budget cap or spend
   manager, and none is to be added. The UI shows the paid-call estimate before each paid action;
   the owner manages the AvalAI credit. An agent makes no paid call without explicit owner approval.

## Explicit exclusions

This decision does **not** authorize a Production flag or credential change, API use, paid
voice/image generation, bulk generation, replacement of approved Start media, deployment, or
publication. It records the standard and the qualification gate only.

## Reversibility

A later owner decision may replace a qualified voice after the same evidence gate, or change the
model/provider after an explicit compatibility and cost review. The article-aware rule and the
approved Start V2 visual contract remain in force unless superseded by a new owner decision.
