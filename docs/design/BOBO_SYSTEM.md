# Bobo system

Bobo is LearnBox's optional study companion: warm, concise, and never a gatekeeper. It supports a learner's next useful action; it does not grade their worth or turn a missed day into a failure.

## Expression contract

| Expression  | Appropriate moment                           | Behaviour                                             |
| ----------- | -------------------------------------------- | ----------------------------------------------------- |
| `welcome`   | opening a session                            | calm invitation to begin                              |
| `encourage` | a difficult card or small streak             | acknowledge effort without exaggeration               |
| `celebrate` | a meaningful completion                      | brief shared delight, never pressure to continue      |
| `recovery`  | returning after a break or oversized backlog | normalise return and point to the short recovery path |
| `focus`     | choosing a session mode                      | protect attention with one clear next step            |

## Non-negotiable learner protections

- Bobo must never shame, guilt, threaten, or compare a learner.
- Bobo must never block study, review, recovery, or settings behind an interaction.
- Animation is decorative and must respect reduced-motion preferences with an equivalent still state.
- Copy remains short, Persian-first and action-oriented; German learning content stays visually LTR.
- Streaks and points are feedback, not a measure of personal success. Recovery language always welcomes the learner back.

## Asset governance

The canonical Bobo appearance was owner-approved as version `1.0.0`: a white, softly furry, single-piece round companion with no visible neck; two short, attached ears next to each other; dark expressive eyes and gentle peach cheeks. Every shipped Bobo asset must be derived from the approved canonical reference sheet, needs an `assetId` and canonical version `1.0.0`; an unversioned asset is a placeholder only.

Do not generate, substitute, or ship a rabbit-like variant: long separated ears, a visible neck, or a separate head/body silhouette are not Bobo.

Changing Bobo's canonical appearance, core expressions, voice, or physical character cues requires explicit owner approval. This preserves a coherent public identity and prevents an AI-generated or temporary visual from silently becoming the product mascot.

## Vocabulary-image direction

Bobo supports memory rather than dominating every image. It may lead actions, emotions and human
situations; the concrete object must lead noun cards; the environment must lead place cards; and
abstract concepts use one Bobo scenario only when it clarifies the meaning. Roughly 70% presence
is an art-direction target, never a quota.

Every vocabulary image has one primary concept, a controlled soft-3D background, no generated
text or watermark, no unapproved Bobo variation, clear mobile-card hierarchy and minimal
irrelevant detail. Visual QA checks semantics, canonical consistency, small-size readability,
clutter, cultural ambiguity, near-duplicates, asset size and light/dark usability.
