# UI QA — Today و کارت واژگان

**مرجع مفهومی:** `docs/design/concepts/today-concept.png` و `card-concept.png`

**پیاده‌سازی:** `apps/website/app/page.tsx` و `globals.css`

## تطبیق بررسی‌شده

| مورد              | مرجع                                     | نتیجهٔ پیاده‌سازی                                             |
| ----------------- | ---------------------------------------- | ------------------------------------------------------------- |
| رنگ و فضا         | پس‌زمینهٔ گرم، سطح سفید، آبی و زردآلویی  | مطابق tokens قفل‌شده پیاده شد.                                |
| سلسله‌مراتب Today | عنوان کوتاه، یک CTA اصلی، سپس خلاصه      | CTA «شروع مرور» یکتا و در دسترس است.                          |
| کارت واژگان       | article، واژهٔ آلمانی، تصویر، cue و flip | کارت دارای برچسب LTR، تصویر مستقل و کنترل flip است.           |
| پاسخ فعال         | چهار درجهٔ پاسخ با تفاوت روشن            | هر چهار کنترل کدنیتیو و قابل‌کلیک‌اند و بازخورد نشان می‌دهند. |
| RTL و موبایل      | فارسی خوانا و چیدمان جمع‌وجور            | viewport 390×844 بررسی شد؛ overflow افقی ندارد.               |
| حرکت کم           | flip کوتاه در مفهوم                      | `prefers-reduced-motion` همهٔ transitionها را کاهش می‌دهد.    |

## مسیر آزموده‌شده

`Today → شروع مرور → برگرداندن کارت → یادم آمد → بازخورد → بازگشت به امروز`

## انحراف‌های آگاهانه

- مفهوم تصویری از mascot عمومی استفاده می‌کند؛ پیاده‌سازی نیز فقط یک نشانهٔ انتزاعی دارد و Bobo نهایی را ادعا نمی‌کند.
- داده‌های روی Today نمونهٔ طراحی‌اند و هنوز به API وصل نشده‌اند.
- Progress کامل به‌عنوان صفحهٔ تعاملی در این برش پیاده نشده است؛ مفهوم و قواعد طراحی آن ثبت شده‌اند.
