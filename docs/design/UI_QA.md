## تطبیق بررسی‌شده

| مورد              | مرجع                                     | نتیجهٔ پیاده‌سازی                                                                                     |
| ----------------- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| رنگ و فضا         | پس‌زمینهٔ گرم، سطح سفید، آبی و زردآلویی  | مطابق tokens قفل‌شده پیاده شد.                                                                        |
| سلسله‌مراتب Today | عنوان کوتاه، یک CTA اصلی، سپس خلاصه      | CTA «شروع مرور» یکتا و در دسترس است.                                                                  |
| کارت واژگان       | article، واژهٔ آلمانی، تصویر، cue و flip | کارت دارای برچسب LTR، تصویر مستقل و کنترل flip است.                                                   |
| تلفظ واژه         | کنترل صدای مستقل روی کارت                | دکمهٔ کدنیتیو تلفظ با زبان `de-DE` و حالتِ نبودِ پشتیبانی مرورگر پیاده شد.                            |
| پاسخ فعال         | چهار درجهٔ پاسخ با تفاوت روشن            | هر چهار کنترل کدنیتیو و قابل‌کلیک‌اند و بازخورد نشان می‌دهند.                                         |
| جلسهٔ چندکارتی    | پیشرفت واضح، کارت بعدی و پایان آرام      | سه کارت نمونه، شمارندهٔ زنده، نوار پیشرفت و ثبت پاسخ‌های هر جلسه پیاده شد.                            |
| RTL و موبایل      | فارسی خوانا و چیدمان جمع‌وجور            | viewport 390×844 بررسی شد؛ overflow افقی ندارد.                                                       |
| حرکت کم           | flip کوتاه در مفهوم                      | `prefers-reduced-motion` همهٔ transitionها را کاهش می‌دهد.                                            |
| Onboarding        | عنوان، سه هدف و CTA در یک قاب آرام       | سه گزینهٔ radio کدنیتیو، انتخاب واضح و دو مسیر ادامه دارد.                                            |
| ورود محلی         | شمارهٔ موبایل، کد ورود و حریم خصوصی      | ورود دو مرحله‌ای با اعتبارسنجی محلی و بازگشت به اصلاح شماره پیاده شد؛ ارسال پیامک هنوز متصل نیست.     |
| آیکون‌های هدف     | خانه، مسیر حرفه‌ای و سفر با رنگ نرم      | SVGهای هم‌خانواده با دایرهٔ رنگی و ضخامت خط یکسان پیاده شدند.                                         |
| نشان آغاز         | نشان LearnBox و موج حافظهٔ خنثی          | نام نوشتاری + موج حافظه پیاده شد؛ نشان کتابِ موقت وارد محصول نشد.                                     |
| واکنش‌پذیری       | ترکیب عمودی و خوانا در موبایل            | در 390×844 بدون overflow افقی و با همهٔ کنترل‌ها بررسی شد.                                            |
| صفحهٔ پیشرفت      | تیتر، نمودار هفتگی، یک بینش و CTA        | نمودار SVG کدنیتیو، بینش زمان و ادامهٔ مرور پیاده شد.                                                 |
| ناوبری پایین      | سه مقصد با انتخاب مشخص                   | Today، واژه‌ها و پیشرفت بعد از onboarding قابل‌کلیک‌اند.                                              |
| بوبو              | نسخهٔ رسمی 1.0.0                         | فقط فایل‌های استخراج‌شده از مرجع تأییدشده در onboarding، Today، بازگشت و ثبت موفقیت بارگذاری می‌شوند. |

## مسیر آزموده‌شده

`Today → شروع مرور → سه کارت → برگرداندن هر کارت → انتخاب پاسخ → بوبوی جشن → بازگشت به امروز`

`Onboarding → انتخاب کار و دانشگاه → ادامه → Today`

`Onboarding → عبور از این مرحله → Today → پیشرفت → ادامهٔ مرور`

`ورود → شمارهٔ موبایل → کد ۵ رقمی → Onboarding`

## انحراف‌های آگاهانه

- داده‌های روی Today نمونهٔ طراحی‌اند و هنوز به API وصل نشده‌اند.
- نشان کتابِ مفهوم Onboarding هنوز نشان رسمی محصول نیست؛ این انحراف عمدی است تا هویت بصری بدون تأیید مالک تثبیت نشود.
- ارسال و اعتبارسنجی واقعی کد پیامکی عمداً فعال نیست؛ رابط ورود آزمایشی این موضوع را صریحاً می‌گوید و تنها پس از اتصال امن سرویس و ارائهٔ دسترسی مالک جایگزین می‌شود.
