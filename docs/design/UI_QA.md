## مسیر آزموده‌شده

`Today → شروع مرور → سه کارت → برگرداندن هر کارت → انتخاب پاسخ → بوبوی جشن → بازگشت به امروز`

`Today → تکمیل سه کارت → بازگشت به Today بدون کارت → focus روی رفتن به واژه‌ها → Words`

`Onboarding → انتخاب کار و دانشگاه → ادامه → Today`

`Onboarding → عبور از این مرحله → Today → پیشرفت → ادامهٔ مرور`

`ورود → شمارهٔ موبایل → کد ۵ رقمی → Onboarding`

## انحراف‌های آگاهانه

- داده‌های روی Today نمونهٔ طراحی‌اند و هنوز به API وصل نشده‌اند.
- نشان کتابِ مفهوم Onboarding هنوز نشان رسمی محصول نیست؛ این انحراف عمدی است تا هویت بصری بدون تأیید مالک تثبیت نشود.
- ارسال و اعتبارسنجی واقعی کد پیامکی عمداً فعال نیست؛ رابط ورود آزمایشی این موضوع را صریحاً می‌گوید و تنها پس از اتصال امن سرویس و ارائهٔ دسترسی مالک جایگزین می‌شود.

## رابط داخلی Admin — بازبینی محتوا (LB-DS-056)

**وضعیت:** پیاده‌سازی و بررسی محلی در Draft PR #266 انجام شده است؛ این کار **merge نشده، منتشر نشده و پذیرفته نشده** است. هیچ بررسی مرورگر، تصویربرداری، axe، صفحه‌کلید واقعی، تضاد رنگ یا staging انجام نشده و ادعا نمی‌شود. تنها محیط اجراشده jsdom/Vitest است.

**مرجع مفهومی:** `docs/design/concepts/admin-content-review-concept-v1.png` — **قرارداد:** `docs/design/D0_VISUAL_LANGUAGE.md` — **پیاده‌سازی:** `apps/admin/app/components/ContentReviewWorkspace.tsx` و `apps/admin/app/globals.css`

**شواهد بررسی محلی:** تست متمرکز وضعیت سرور از ۳ شکست (RED) به ۱۵/۱۵ سبز رسید؛ کل تست‌های Admin ‏۲۸ فایل/۱۶۹ تست پاس شد؛ `typecheck` و `build` ادمین پاس شد؛ Prettier روی همهٔ فایل‌های لمس‌شده پاس شد؛ اعتبارسنج‌های queue/documentation-governance/continuity/dashboard و `git diff --check` پاس شدند.

**آنچه هنوز بررسی نشده:** پذیرش بصری و دسترس‌پذیری روی مرورگر واقعی در ۳۹۰ پیکسل، حلقهٔ فوکوس و حرکت کم؛ خوانایی و تضاد رنگ در عمل؛ رفتار روی staging؛ و بازبینی مستقل سرِ دقیق. هیچ‌کدام از این‌ها با این کار ادعا نمی‌شوند.

**تغییر نکرده:** هیچ مسیر fetch، توکن CSRF، کلید idempotency، نوشتن بررسی، تصمیم سردبیری یا حالت سرور تغییر نکرده است؛ پیش‌نمایش محلی، پنل انتشار بسته و پنل اسپلش دست‌نخورده‌اند.
