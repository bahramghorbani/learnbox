# Information architecture

## سطح یادگیرنده

| مقصد        | پرسش کاربر                    | اقدام اصلی                     |
| ----------- | ----------------------------- | ------------------------------ |
| امروز       | «الان چه بخوانم؟»             | شروع جلسهٔ پیشنهادی            |
| یادگیری     | «در این جلسه چه می‌شود؟»      | دیدن/برگرداندن کارت و ثبت پاسخ |
| واژه‌های من | «واژهٔ خودم کجاست؟»           | افزودن یا مرور کارت شخصی       |
| پیشرفت      | «چه بهتر شده و گام بعد چیست؟» | شروع جلسهٔ بعدی                |
| پروفایل     | «تنظیمات و هدف من چیست؟»      | مدیریت هدف، یادآور، صدا و حساب |

ناوبری پایین فقط پس از onboarding کامل نمایش داده می‌شود. صفحهٔ Today نقطهٔ ورود پیش‌فرض است و یک اقدام اصلی دارد.

## سطح مدیریت

دامنه‌های مستقل مدیریت: کاربران، محتوا، رسانه، بررسی/انتشار، محصولات و پرداخت، پیکربندی، اعلان، گزارش و audit. پنل مدیریت هرگز همان API یا سطح دسترسی کاربر را افشا نمی‌کند.
