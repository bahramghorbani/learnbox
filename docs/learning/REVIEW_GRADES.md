# Review grades

`فراموش کردم`, `سخت بود`, `یادم آمد`, `کاملاً بلد بودم` map to forgot, hard, remembered, and mastered. Grades alter interval and state; later UI may show timing without clutter.

The copy communicates recall confidence, not a promise about an exact next date. The user can suspend or archive cards later; neither action deletes review history.
