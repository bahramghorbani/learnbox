# Project Vision and Scope

## Vision

LearnBox should feel like an interactive animated story, not a standard app landing page.

BuBu is the lead character. The visitor follows BuBu through a short visual journey that explains why vocabulary is forgotten, how LearnBox organizes review, how repetition becomes a habit, and how the user can begin.

DuDu is a secondary official character and may appear only where the storyboard or the user explicitly requires it.

## Audience priority

1. German learners preparing for work migration.
2. German learners preparing for academic migration.
3. Learners focused on practical conversation.
4. General German learners.
5. Exam-oriented learners.

## Core message

LearnBox turns vocabulary review into a clear, motivating, repeatable learning system.

## Primary calls to action

- Download for Android from Café Bazaar.
- Open the web app for iPhone, iPad, and supported browsers.
- Watch how LearnBox works.

## Version 1 scope

The first production release should contain:

- cinematic hero section,
- story-driven scroll experience,
- explanation of the forgetting problem,
- visual Leitner and spaced review concept,
- core learning features,
- learning paths,
- gamification,
- real app previews,
- platform download section,
- social links,
- footer,
- default theme,
- one verified seasonal theme implementation,
- SEO foundation,
- analytics-ready structure,
- responsive layouts,
- reduced-motion mode,
- deployment documentation.

## Explicitly out of scope for version 1

Do not implement unless already present and required for integration:

- admin dashboard,
- application management panel,
- full CMS,
- blog engine,
- teacher portal,
- enterprise portal,
- authentication,
- learning account dashboard,
- payment flow,
- a replacement for the LearnBox app,
- an unrelated design system migration.

## Product truth rule

Never claim or visually imply a feature, distribution channel, platform availability, or product capability that is not available or approved.

Place uncertain future features behind clear labels such as “به‌زودی” and centralize them in configuration.

## Content language

The primary experience is Persian and RTL.

Code, file names, component names, and documentation may remain English.

Support for localization should be possible later, but version 1 should not become a localization project.
