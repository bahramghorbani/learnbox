# Roadmap and Definition of Done

## Phase 0 — Repository audit

Deliverables:

- repository map,
- detected stack,
- existing assets and systems,
- chosen integration location,
- risk notes.

Exit condition:

`REPOSITORY AUDIT COMPLETE`

## Phase 1 — Scope lock

Deliverables:

- validated scope,
- final CTA set,
- feature truth table,
- content placeholders identified.

Exit condition:

`SCOPE LOCKED`

## Phase 2 — Storyboard lock

Deliverables:

- scene list,
- scene copy,
- interaction intent,
- character usage,
- mobile behavior,
- reduced-motion behavior.

Exit condition:

`STORYBOARD LOCKED`

## Phase 3 — Visual direction

Deliverables:

- hero style frame,
- forgetting scene frame,
- Leitner scene frame,
- learning paths frame,
- gamification frame,
- download frame,
- seasonal theme frame.

Exit condition:

`VISUAL DIRECTION LOCKED`

## Phase 4 — Static experience

Deliverables:

- complete semantic page,
- complete RTL layout,
- working CTAs,
- responsive static sections,
- SEO metadata,
- placeholder assets where necessary.

Exit condition:

`STATIC EXPERIENCE COMPLETE`

## Phase 5 — Motion foundation

Deliverables:

- motion tokens,
- GSAP context pattern,
- scene lifecycle,
- responsive motion profiles,
- reduced-motion behavior,
- performance safeguards.

Exit condition:

`MOTION FOUNDATION COMPLETE`

## Phase 6 — Scene implementation

Implement in order:

1. Hero
2. Forgetting problem
3. Leitner system
4. Multimedia vocabulary
5. Learning paths
6. Gamification
7. Product screens
8. Downloads
9. Social channels
10. Final CTA

A scene is complete only when:

- desktop works,
- mobile works,
- reduced motion works,
- assets are optimized,
- tests pass,
- no critical console errors exist.

## Phase 7 — Theme engine

Deliverables:

- default theme,
- seasonal demo,
- theme switch,
- theme documentation,
- verified character preservation.

Exit condition:

`THEME SWITCHING VERIFIED`

## Phase 8 — Production content

Deliverables:

- real links,
- real QR codes,
- real app screenshots,
- approved release status,
- official social links,
- Open Graph image,
- favicon,
- legal links.

Exit condition:

`PRODUCTION CONTENT COMPLETE`

## Phase 9 — QA

Required checks:

- Chrome
- Safari
- Firefox
- iPhone viewport
- Android viewport
- small mobile
- large desktop
- slow connection
- reduced motion
- keyboard navigation
- basic screen-reader flow
- broken links
- missing images
- layout shift
- console errors
- build errors
- deployment preview

Exit condition:

`QA PASSED`

## Phase 10 — Deployment

Deliverables:

- production deployment,
- SSL check,
- domain check,
- smoke tests,
- rollback steps,
- deployment guide.

Exit condition:

`PRODUCTION DEPLOYMENT VERIFIED`

## Phase 11 — Handover

Deliverables:

- README,
- architecture notes,
- theme guide,
- content update guide,
- QA report,
- change log,
- project state.

Final state:

```text
LearnBox Website v1.0
Status: COMPLETE
Production: VERIFIED
```
