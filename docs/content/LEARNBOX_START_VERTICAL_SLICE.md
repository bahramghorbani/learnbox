# LearnBox Start — 20-item vertical slice plan

The first slice is a validation task, not content publication. It must be balanced across concrete nouns, verbs, adjectives, emotions, places, foods, household objects and daily expressions.

| Group                           | Target count | Example intent                        |
| ------------------------------- | -----------: | ------------------------------------- |
| Concrete and household nouns    |            4 | object visually dominant              |
| Food and drink                  |            3 | object clear, Bobo optional           |
| Places                          |            2 | environment carries meaning           |
| Core verbs                      |            4 | Bobo may demonstrate action           |
| Adjectives and emotions         |            3 | clear state/expression                |
| Daily expressions and questions |            4 | practical scenario, not text in image |

For every item: complete `LearningVocabularyItem` data, word/sentence audio, approved image, schedule creation, review grading, offline download/recovery, progress update and appropriate Bobo example. Validate in PWA and mobile, at card size and offline, with linguistic, visual, audio and UX acceptance recorded. Only then may the first ~50-item batch be proposed.
