# LearnBox Start — 350-item selection method

The goal is about 350 high-value A1 words and practical expressions, not an alphabetical list.

1. Collect candidates from CEFR-aligned and editorially licensed/referenceable sources.
2. Normalize lemma/expression, article, inflection and pronunciation; retain provenance.
3. Remove exact and near duplicates, including concepts that would create indistinguishable cards.
4. Score candidates for A1 suitability, practical frequency, daily/migration usefulness, learning progression, visual teachability and category balance.
5. Select across greetings, people, home, food, shopping, time, transport, places, work/study, health, weather, clothing, core verbs/adjectives, questions and early administration.
6. Write a simple German definition, Persian meaning, natural practical example and grammar note.
7. Validate German grammar, Persian writing/translation, CEFR, duplicate risk and provenance.
8. Release only reviewed batches: 20-item vertical slice, then approximately 50 items per version with app validation and rollback.

Acceptance: a selected item has a clear practical rationale, one teachable visual concept, full required metadata and no unresolved linguistic or licensing issue.
